[ AGGRESSION ]

SYN FLOOD

COST: 1 | DMG: 5 | EFFECT: [Congested] (-1 Thread Regen)

Overwhelms the target's queue, slowing down their resource generation for the next turn.

Real Life: A form of Denial-of-Service attack that abuses the TCP 3-way handshake. The attacker sends a rapid succession of SYN (synchronize) requests to a target's ports but never sends the final ACK (acknowledge) to complete the handshake. This leaves the server holding open "half-open" connections until its memory queue is entirely exhausted, preventing legitimate traffic from connecting.

SQL INJECTION

COST: 3 | DMG: 20 | EFFECT: Standard Damage

A solid, medium-tier attack that reliably drains opponent health.

Real Life: Exploiting improperly sanitized web inputs to run unauthorized database queries. By inserting malicious SQL syntax into a login or search field (e.g., `' OR 1=1; --`), an attacker can trick the backend database into dumping protected tables, modifying data, or bypassing authentication entirely.

RANSOMWARE

COST: 5 | DMG: 15 | EFFECT: [Encrypted] (Setup/Recovery costs 2x)

Locks down the opponent's file system, making it incredibly expensive for them to heal or build resources next turn.

Real Life: Malicious software that infiltrates a network and violently encrypts the victim's files using strong cryptography. The attackers hold the private decryption key hostage, demanding a ransom (usually in cryptocurrency) to restore access to the infrastructure.

DDOS BOTNET

COST: ALL | DMG: Threads x 5 | EFFECT: Scales with resources

Consumes all your available Threads to unleash a massive, scaling wave of damage.

Real Life: Distributed Denial of Service. Instead of attacking from one machine, the hacker uses a "botnet"—thousands of malware-infected IoT devices, routers, and PCs spread across the globe. They command this zombie army to simultaneously flood the target IP with junk packets, instantly collapsing the target's bandwidth capacity.

RECURSIVE DELETE (rm -rf /)

COST: 7 | DMG: 45 | EFFECT: Massive Damage

The ultimate kinetic payload. Capable of ending a duel in two hits, but highly susceptible to Honeypot recoil.

Real Life: A catastrophic Linux/Unix terminal command. `rm` removes files, `-r` tells it to act recursively through all folders, `-f` forces the deletion without asking for confirmation, and `/` targets the root directory. If executed with root privileges, the operating system effectively deletes itself alive.

[ DEFENSE ]

PACKET SNIFFER

COST: 1 | DMG: 0 | EFFECT: [Traced] (+50% DMG to target next attack)

Tags the opponent. Your next Aggression move against them will deal catastrophic critical damage.

Real Life: Deploying a tool (like Wireshark or tcpdump) on a network interface to intercept and log traffic passing over a digital network. It allows an operator to inspect the raw hex/ASCII data of packets to find plain-text passwords, session cookies, or map the internal topology.

DEPLOY HONEYPOT

COST: 2 | DMG: 0 | EFFECT: Blocks 100% of attack + 20 Recoil Damage

The ultimate parry. If the opponent attacks on the exact same turn, they take heavy damage. If they don't, you wasted 2 Threads.

Real Life: A decoy computer system deliberately set up with vulnerabilities to attract hackers. It acts as a trap; when attackers breach it, they are isolated from the real production network, while sysadmins monitor their tactics, trace their origin IPs, and gather threat intelligence.

HARD FIREWALL

COST: 2 | DMG: 0 | EFFECT: Mitigates 60% of incoming damage

A reliable block that guarantees you will survive a heavy barrage.

Real Life: A dedicated hardware appliance sitting at the perimeter of a network. It uses Access Control Lists (ACLs) and stateful packet inspection to scrutinize incoming and outgoing traffic, dropping connections that violate security policies before they reach internal servers.

IP SPOOFING

COST: 3 | DMG: 0 | EFFECT: Evades 100% of incoming attacks

A costly but guaranteed dodge maneuver.

Real Life: The creation of Internet Protocol (IP) packets with a false source IP address. By forging the packet header, the attacker obscures the true origin of the traffic, making it incredibly difficult for automated defenses to track or ban the actual source.

KILL PROCESS

COST: 4 | DMG: 0 | EFFECT: Cancels opponent's Setup/Recovery + 15 DMG

A brutal interrupt. Use this when you predict the opponent is going to try to heal or Overclock.

Real Life: Sending a termination signal (like SIGKILL or `kill -9` in Linux) directly to the kernel to immediately halt a running process. This is used by sysadmins to terminate rogue scripts, malware execution, or frozen applications that are consuming 100% of CPU resources.

[ SETUP & RECOVERY ]

OVERCLOCK CPU

COST: 0 | DMG: 0 | EFFECT: [Overclocked] (Regen 6 Threads next turn)

Sacrifices your current turn to give you a massive resource advantage on the next one.

Real Life: Configuring computer hardware (CPU, GPU, or RAM) to operate at a clock rate faster than certified by the manufacturer. While it yields higher performance and faster processing times, it generates severe excess heat and risks hardware instability or permanent thermal damage.

FLUSH DNS

COST: 1 | DMG: 0 | EFFECT: Clears all negative status effects

The cleanse. Removes Congestion, Encryption, and Tracing from your system.

Real Life: Clearing the local DNS (Domain Name System) cache on a machine. If a network gets poisoned or a domain moves to a new IP, the machine might route traffic to a dead or malicious server. Flushing the cache forces the computer to re-query the network for clean routing tables.

RESTORE BACKUP

COST: 3 | DMG: 0 | EFFECT: Restores 25 HP

Standard healing to keep you in the fight after taking heavy fire.

Real Life: The ultimate failsafe for any sysadmin. When a server's root directory is corrupted or encrypted by ransomware, the fastest mitigation is wiping the infected drive entirely and reimaging the server from an air-gapped, untainted backup snapshot taken hours prior.

DEPLOY MINER

COST: 3 | DMG: 0 | EFFECT: [Mining] (+1 Passive Thread Regen), take 5 DMG

A permanent economy buff at the cost of damaging your own hardware.

Real Life: Cryptojacking. Surreptitiously installing cryptocurrency mining scripts onto a server infrastructure. The miner silently hijacks CPU cycles to calculate hashes for blockchain validation, severely degrading the server's lifespan and performance while generating illicit revenue for the attacker.

ZERO-DAY R&D

COST: 4 | DMG: 0 | EFFECT: [Weaponized] (Next attack ignores all defenses)

Prepares an unblockable attack. If you use this, the opponent's Firewalls and Honeypots become useless next turn.

Real Life: A "zero-day" is a software vulnerability that is entirely unknown to the software vendor. Because the developers have had "zero days" to patch it, traditional antivirus definitions and firewalls cannot detect the exploit, giving the attacker guaranteed, uncontested entry into the system.

[ NETWORK STATUS EFFECTS ]

[ CONGESTED ]

Game Mechanic: The operator regenerates 1 less Thread on the following turn. Cancels out Overclocked.

Real-World Equivalent: Network Congestion. The network is flooded with traffic, filling up routing queues and causing packet loss, significantly slowing down the operator's ability to process new commands.

[ ENCRYPTED ]

Game Mechanic: The operator's [ SETUP & RECOVERY ] payloads cost double the Threads to execute on the next turn.

Real-World Equivalent: Ransomware Encryption. Critical system files are locked behind cryptographic keys. Attempting to run standard recovery or setup operations becomes computationally massive as the system struggles to read locked data.

[ TRACED ]

Game Mechanic: The operator takes +50% Damage from the next [ AGGRESSION ] payload they are hit with.

Real-World Equivalent: Traffic Analysis. An opponent has intercepted unencrypted packets and mapped out the operator's internal network architecture, allowing subsequent attacks to strike critical vulnerabilities directly.

[ WEAPONIZED ]

Game Mechanic: The operator's next attack is completely unblockable. It shreds Firewalls, bypasses Honeypots, and ignores IP Spoofing.

Real-World Equivalent: Zero-Day Exploit. The operator has deployed an attack targeting a software vulnerability that is entirely unknown to the vendor. Because it is unknown, no antivirus signatures or firewall rules exist to stop it.

[ OVERCLOCKED ]

Game Mechanic: The operator generates 6 Threads on the next turn instead of the standard 2. Cancelled by Congested.

Real-World Equivalent: Hardware Overclocking. Forcing the CPU's clock multiplier past the manufacturer's official limits to achieve a massive, temporary burst of processing power.

[ MINING ]

Game Mechanic: The operator takes 5 flat damage but gains a permanent +1 passive Thread regeneration for the rest of the match.

Real-World Equivalent: Cryptojacking / Botnets. Dedicating background server resources to constantly mine cryptocurrency or run distributed tasks. It permanently generates resources, but the constant 100% CPU load physically degrades the hardware over time.
